## Origins in Beater

Beater was developed as a **Python music-production application**, with work spanning audio synthesis, sequencing, MIDI support, and audio processing.

Its documented implementation included a Tkinter-based editor, a PySide6 access interface, a FastAPI backend, SQLite and SQLAlchemy integration, and automated testing.

This background describes **Beater's implementation**. It provides historical context for Delta; it does not establish Delta's current features, dependencies, or architecture.
